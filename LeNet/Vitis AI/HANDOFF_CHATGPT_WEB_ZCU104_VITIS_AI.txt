Algoritmo exato para o MNIST, cuja distribuicao de teste nao e balanceada:

  labels = labels.reshape(-1)
  rng = numpy.random.default_rng(20260825)
  groups = []

  para class_id de 0 a 9:
      indices = flatnonzero(labels == class_id)
      rng.shuffle(indices)
      groups.append(indices)

  balanced_thousand = stack([g[:100] para g em groups], axis=1).reshape(-1)
  remainder = concatenate([g[100:] para g em groups])
  rng.shuffle(remainder)
  order = concatenate([balanced_thousand, remainder])

  selected_N = order[:N]

  preservar timestamps monotonic e wall clock;
  amostrar durante ciclos ou janelas suficientemente longas;

  integrar cada amostra por sobreposicao com o intervalo do ciclo;
  reportar cobertura temporal;
  nao somar rails que se sobrepoem.

Formulas:

  energia_total_J = integral da potencia ativa no tempo
  potencia_dinamica_W = max(potencia_ativa_W - potencia_idle_W, 0)
  energia_por_inferencia_mJ = 1000 * energia_total_J / inferencias
  energia_dinamica_por_inferencia_mJ =
      1000 * energia_dinamica_J / inferencias

potencia_media/FPS, com conversao de J para mJ.
