# Artefatos exportados

Este diretório reúne cópias dos IPs hls4ml exportados durante a exploração de fatores de reutilização. Os pacotes preservam a estrutura necessária para inclusão no catálogo de IP do Vivado.

A origem experimental, a configuração efetiva e os resultados de cada variante permanecem documentados em `../H1/`. Estas cópias foram mantidas para facilitar a reutilização dos IPs sem depender dos diretórios completos de síntese.
